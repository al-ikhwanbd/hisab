আল-ইখওয়ান হিসাব — OFFLINE VERSION

এটি মূল Online FINAL MASTER-এর আলাদা Offline সংস্করণ। মূল Online ফাইল/সাইট এতে পরিবর্তন করা হয়নি।

ব্যবহার:
1) প্রথমবার ফোন/কম্পিউটারে ইন্টারনেট চালু রেখে এই Offline Version GitHub Pages/HTTPS-এ খুলুন।
2) ডাটা স্বয়ংক্রিয়ভাবে Supabase থেকে এই ডিভাইসের IndexedDB-তে কপি হবে।
3) Admin panel-এ একবার Online Admin Login করুন। এরপর এই ডিভাইসে “অফলাইন অ্যাডমিন প্রবেশ” ব্যবহার করা যাবে।
4) এরপর ইন্টারনেট বন্ধ করেও সদস্য, মাসিক জমা, লভ্যাংশ, খরচ, তহবিলের খাত ও নোটিশ দেখা/যোগ/সম্পাদনা/মুছে ফেলা যাবে।
5) ইন্টারনেট ফিরে এলে Admin অবস্থায় “🔄 সিঙ্ক” চাপলে Offline-এ করা পরিবর্তনগুলো Supabase-এ পাঠানো হবে এবং সর্বশেষ ডাটা আবার ডিভাইসে নামবে।

গুরুত্বপূর্ণ:
- এই ZIP-টি মূল Online FINAL MASTER-এর বিকল্প নয়; এটি আলাদা Offline Version।
- Offline Admin অনুমতি শুধু সেই ডিভাইসের স্থানীয় storage-এ রাখা হয়; ব্যক্তিগত/বিশ্বস্ত ডিভাইসে ব্যবহার করুন।
- Browser-এর site data/IndexedDB মুছে ফেললে offline copy মুছে যেতে পারে; তাই নিয়মিত Online Sync রাখুন।
